### About Me

I am a **Full Stack Developer and Software Engineer based in Bangladesh 🇧🇩**, focused on building scalable, secure, and user-friendly web and mobile applications. I work across the full development lifecycle — from database design and REST API development to responsive frontends and cross-platform mobile apps.

**Areas of work:**

- Full stack web applications with **React.js, Next.js, Node.js & Express.js**
- Cross-platform mobile applications with **Flutter**
- RESTful API design, integration, authentication & role-based access control
- Business management systems, e-commerce platforms & transport management solutions
- Database design with **PostgreSQL, MongoDB & MySQL**
- Deployment and cloud technologies
